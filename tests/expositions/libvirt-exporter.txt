# Recorded from ccv-admin, a standalone SEAPATH hypervisor running seven

# series `app/cluster/libvirt.py` reads plus a few of its neighbours, so a
# reader that widens its list meets the shapes it will actually get.
#
# Two facts in here are the ones that matter. `VMUADMIN` is a domain the
# machine runs and the inventory does not declare, which is the guest most
# likely to need stopping. And it is shut off, which is a state the page has to
# tell apart from a guest nothing reported.

# were read from the same machine

# EITCS's and EITDeb13's `sda` are empty drives, and repeat the capacity of
# the disk read before them. VMUADMIN, shut off, publishes no capacity.
