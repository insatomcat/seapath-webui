Console

{# `Ctrl+]` is what leaves `virsh console`, and on a French keyboard it is a chord few people find, so the byte gets a button of its own. #}

This is the guest's serial port, opened by vm-mgr console on the machine named above. In a cluster it asks Pacemaker where the guest runs and reaches that libvirt as libvirtadmin; on a standalone machine it reads its own. Libvirt allows one such session per guest. Detach, or Ctrl+], leaves it, and a guest with no serial console in its XML shows nothing at all.

This is a shell on the machine named above, opened over the same SSH path a run uses, so it lands on the ansible account. On a SEAPATH machine that account may run /bin/sh as root with no password: sudo sh is root, and any other sudo asks for a password. Nothing typed here is part of the desired state: a change made in this terminal is invisible to the inventory and is undone by the next run that touches it.

Graphic console

{# The operator's own system keeps this chord, so it is sent from here. #}

This is the guest's screen, from the VNC server QEMU runs on the loopback of the machine named above, reached over the SSH path a run uses and a relay run as root there. Keys travel as the keys of your keyboard, so the guest applies its own layout; Escape goes to the guest, and Close leaves. The pointer is a tablet, never captured. The screen is shared: another operator opening it sees the same one. Nothing done here is recorded or part of the desired state.
