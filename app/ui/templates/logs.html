Asking the machines

Time Machine Unit Message

Every machine is asked at once, over the same SSH connection a run makes, and one that does not answer is named above rather than failing the reading. The lines of all of them are interleaved by their own timestamps, which is meaningful because the cluster holds its clocks with PTP. Nothing is kept here: a machine that has been reinstalled, or whose journal has rotated, no longer holds what it printed.
