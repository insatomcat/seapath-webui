Desired state

The inventory is the desired state of these machines, and this page is the only thing that edits it. Every change is a commit. Nothing here touches a machine: that is the System page.

Import an inventory

A site that already has an inventory brings it here. The file is committed whole and becomes the desired state, and the version it replaces stays one revert away in the history below. Editing it afterwards changes the lines you change and leaves the rest of the file exactly as you wrote it, comments included.

One machine, guided

The same file as below, edited field by field, with what this machine reports about itself: its real interfaces, its disks by their stable path, its CPU count. A GRUB password typed here is stored as the PBKDF2 hash and never in clear.

    The files beside it
    
    
    
      An inventory is rarely alone. upload_extra_files,
      iptables, syslog_ng_client, cephadm
      and the VM roles all name a file this machine has to hold, and a run
      mounts this folder where a checkout of seapath-ansible would
      be. A path written ../inventories_private/quadlet.network
      means the same thing here as it does on a control machine.
