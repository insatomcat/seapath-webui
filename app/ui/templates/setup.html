Desired state

This form edits the inventory. Nothing here touches the machine: saving makes a commit, and applying runs the SEAPATH playbooks against it.

Import an inventory

A site that already has an inventory brings it here. The file is committed whole and becomes the desired state, and the version it replaces stays one revert away in the history below. Editing it afterwards changes the lines you change and leaves the rest of the file exactly as you wrote it, comments included.

Machine

The address this machine answers on, or the one the network configuration is about to give it. Declaring an address it does not have yet is normal at commissioning.

Time

The interface receiving PTP frames. Discovery cannot know which one that is: it is a cabling fact, not something the machine can observe.

The fallback if PTP is lost.

Accounts

Hashed before it is written. The inventory is in git, so a password in clear would be in the audit trail forever. Leave empty to keep the current one.

Real time (expert)

Latency is the product. These fields change the guarantees the machine makes to the protection functions running on it.
