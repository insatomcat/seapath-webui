Real time conformance

Reading this machine

A conformance check compares the machine with the value the inventory declares for it, and the fix for a mismatch is an inventory edit followed by a run. An advice check has nothing to compare against: it reports what the machine came out with and says what it costs. Neither kind is fixed from this page, because nothing here writes to a host.

CPU map

Grouped by physical core, so the two threads of one core sit together. An isolated CPU whose sibling is not isolated shares its execution units with whatever the scheduler puts there, which is the case the outline marks.

Hardware interruptions

Reading past measurements

This is the one measurement no check above can make. A System Management Interrupt takes the CPU into firmware without telling the kernel, so the time is missing from the kernel's own accounting and from the cyclictest figures. A machine correctly isolated that still misses its deadline is either a firmware problem or a configuration one, and this separates them. Nothing in the inventory reaches it: the fix is in the BIOS.
