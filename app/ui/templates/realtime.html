Reading this machine

A conformance check compares the machine with the value the inventory declares for it, and the fix for a mismatch is an inventory edit followed by a run. An advice check has nothing to compare against: it reports what the machine came out with and says what it costs. Neither kind is fixed from this page, because nothing here writes to a host.

CPU map
