Reaching the other machines

A run is Ansible over SSH, and this node reaches only itself until it is given a way to reach the others. Both steps below are deliberate acts, and both are undone in one click.

Site key

The private half of the key the ISO already installed in the ansible account of every machine, the one a conventional control machine holds. This key is root on every machine that trusts it. Uploading it here makes this node as capable as that control machine. It is stored 0600, never sent back out and never logged, and only the fingerprint is displayed. A key protected by a passphrase is refused, because nothing here can type one during a run.

Host keys

Read over the network with ssh-keyscan, which means the answer could come from whoever sits between these machines. Compare each fingerprint against ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub on the machine itself before accepting it. Nothing is written until you do.
